<p>கல்வியாளர்க்கான சிகில்ஸ்ஃயூச்சர் என்னும் சிங்கப்பூர்க் கல்வி அமைச்சின்
பெருந்திட்டம் கல்வியாளர்கள் பெற்றிருக்க வேண்டிய எதிர்காலத் திறன்களை அறுவகைப்
பிரிவுகளில் பகுத்தளித்துள்ளது. அவையாவன:</p>
<ul data-tight="true" class="tight">
<li>
<p>வேறுபடுத்தப்பட்ட கற்பித்தல்</p>
</li>
<li>
<p>மின்வழிக் கற்பித்தல் முறைமை</p>
</li>
<li>
<p>வினவல்வழிக் கற்றல்</p>
</li>
<li>
<p>மதிப்பீட்டுப் படிப்பறிவு</p>
</li>
<li>
<p>சிறப்புக் கல்வித் தேவைகள்</p>
</li>
<li>
<p>நற்பண்பு குடியில் கல்வி</p>
</li>
</ul>
<p>இவற்றுள் முதல் நான்கு பிரிவுகள் மட்டும் குவிநோக்கமிட்டு இந்நூலில் தொகுத்தளிக்கப்பட்டுள்ளன.</p>
